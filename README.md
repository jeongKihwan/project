# 리뷰인사이트 MVP

## 실행

```bash
cp .env.example .env
npm run dev
```

`http://localhost:3000`에서 실행됩니다. Node.js 22.5 이상이 필요합니다. 내장 SQLite를 사용하므로 별도 패키지 설치가 필요 없습니다.

## 현재 결제 모드

기본값은 `MockPaymentProvider`입니다. 결제 생성, 서버 검증, 결제 ID 중복 방지, 크레딧 원장 지급 흐름을 실제와 같은 방식으로 검증합니다. 실결제 전환 시 결제 제공업체의 서버 Secret Key를 환경변수에만 설정하고 `providers/payment/`에 provider를 연결합니다. 카드번호와 CVC는 이 서버에 저장하지 않습니다.

## 보안 원칙

- 이메일과 비밀번호만 가입에 사용합니다.
- CSV에서는 `댓글` 열만 분석에 사용합니다.
- 이메일, 전화번호, 주민번호, 카드번호, 주소 형태 데이터는 AI 분석 전 마스킹합니다.
- 분석과 결제 원장은 SQLite DB에 트랜잭션으로 기록합니다.
- 결제 ID는 유니크 제약으로 크레딧 중복 지급을 막습니다.
